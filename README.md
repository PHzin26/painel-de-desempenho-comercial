# 📊 Painel de Desempenho Comercial

Dashboard desenvolvido em Microsoft Power BI para análise de vendas e desempenho comercial.

## 🎯 Objetivo

O projeto tem como objetivo analisar os principais indicadores de desempenho comercial, permitindo visualizar informações relacionadas a vendas, custos, lucro e margem de lucro ao longo do tempo.

## 📌 Principais análises

- Valor de venda por modo de envio
- Custo médio de envio por mercado
- Média do valor de venda e acompanhamento de meta
- Lucro médio por categoria
- Evolução da margem de lucro ao longo do tempo

## 🛠️ Ferramentas utilizadas

- Microsoft Power BI
- DAX
- Modelagem de dados
- Visualização de dados
